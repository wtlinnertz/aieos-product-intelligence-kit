# Pivot Decision Record

A lightweight trace artifact used when discovery learning triggers Pattern 1 (Problem Reframe) or Pattern 2 (Hypothesis Revision) in an active discovery engagement.

This record is **not a governed artifact** — it has no validator, freeze point, or downstream dependency. It exists to make the iteration traceable and auditable, and to require explicit human approval before artifact revisions begin.

File as `pivot-decision-{date}.md` in the engagement's working directory.
